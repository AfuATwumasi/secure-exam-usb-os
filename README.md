# secure-exam-usb-os
Secure bootable USB-based OS for controlled BYOD examinations


## 📌 Project Overview
This project aims to design and implement a secure, USB-bootable operating system for conducting online examinations in a controlled environment.

## 🎯 Objectives
- Create a controlled OS environment for exams
- Support Bring-Your-Own-Device (BYOD)
- Prevent cheating through system-level restrictions
- Integrate with LMS platforms such as Moodle

## 🧰 Technologies (Planned)
- Linux (Custom OS)
- Python (Flask)
- HTML, CSS, JavaScript
- MySQL / SQLite
- LAN-based network control
